# AutoCare 360 Mobile — Entrega Final del Proyecto Móvil 2026

## 📋 Resumen del Sistema Desarrollado
- **Tecnología Frontend Móvil:** React Native, Expo Router (file-based routing), TypeScript y StyleSheet/Flexbox.
- **Backend Integrado:** Spring Boot + PostgreSQL con REST HTTP, Hibernate y arquitectura por capas.

## 🎯 Cobertura de las 15 Guías del Laboratorio
1. ✅ **Guía 01:** Entorno Android Studio, SDK, ADB, AVD y primera app en Expo.
2. ✅ **Guía 02:** Componentes presentacionales, props, estado con useState y paleta visual.
3. ✅ **Guía 03:** Navegación por archivos con Expo Router (Stack layout, params y retornos).
4. ✅ **Guía 04:** Formularios controlados, TextInput, validación de placas y correos.
5. ✅ **Guía 05:** Estado compartido global con ParkingContext y CRUD local de clientes.
6. ✅ **Guía 06:** Relación 1:N entre Clientes y Vehículos con modal de confirmación.
7. ✅ **Guía 07:** Asincronía, useEffect, ciclo de vida e indicadores de carga.
8. ✅ **Guía 08:** Persistencia asíncrona HTTP con fetch/API REST en Spring Boot.
9. ✅ **Guía 09:** Búsqueda en tiempo real, filtros dinámicos, paginación y FlatList.
10. ✅ **Guía 10:** Dashboard ejecutivo de métricas y diálogos modales ConfirmModal.
11. ✅ **Guía 11:** Autenticación JWT, pantalla de Login e inyección Bearer con SecureStore.
12. ✅ **Guía 12:** Caché local nativo con SQLite (expo-sqlite) para resiliencia offline.
13. ✅ **Guía 13:** Permisos nativos de cámara/galería (expo-image-picker) y subida multipart.
14. ✅ **Guía 14:** Pruebas automatizadas unitarias con Vitest y control con expo-doctor.
15. ✅ **Guía 15:** Perfiles de compilación EAS (APK/AAB), variables de entorno y entrega final.
