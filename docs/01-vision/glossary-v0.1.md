# Glosario v0.1 — AutoCare 360

| Término | Significado inicial |
|---|---|
| Taller | Negocio multimarca que repara y da mantenimiento a vehículos. |
| Cliente / propietario | Persona dueña del vehículo que recibe el servicio y puede consultar y aprobar desde el móvil. |
| Vehículo | Automóvil ingresado al taller, identificado por placa o VIN y asociado a un propietario activo. |
| Placa / VIN | Identificadores del vehículo que no deben duplicarse en el sistema. |
| Servicio de catálogo | Tipo de trabajo que el taller ofrece y que puede incluirse en una orden o estimación. |
| Orden de servicio | Registro que sigue un vehículo desde su recepción hasta su entrega. |
| Orden activa principal | Orden en curso de un vehículo; solo puede haber una, salvo autorización administrativa registrada. |
| Estado de la orden | Etapa de la orden: ABIERTA, DIAGNOSTICO, ESPERA_APROBACION, EN_TRABAJO, LISTA_ENTREGA, ENTREGADA o CANCELADA. |
| Diagnóstico preliminar | Evaluación inicial del vehículo que se hace al recibirlo para definir el trabajo. |
| Tarea técnica | Trabajo específico de una orden, con técnico responsable y estado. |
| Estimación | Cálculo de costos y alcance del trabajo que el cliente debe aprobar o rechazar. |
| Ítem de estimación | Línea de una estimación: un servicio o repuesto con su costo estimado. |
| Versión de estimación | Nueva versión de la estimación que se genera cuando cambian costos o alcance. |
| Aprobación del cliente | Decisión de aprobar o rechazar una estimación, con fecha y decisión registradas. |
| Evidencia | Archivo adjunto (por ejemplo, foto) asociado a una orden y con descripción. |
| Historial de estado | Registro de cada cambio de estado de una orden, con fecha y responsable. |
| Entrega | Cierre de la orden: se devuelve el vehículo registrando fecha, kilometraje de salida y observaciones. |
| Kilometraje de salida | Lectura del odómetro al momento de entregar el vehículo. |
| Notificación | Aviso al propietario sobre el avance de su orden o la necesidad de aprobar una estimación. |

> Este glosario es v0.1. Los significados pueden refinarse cuando aparezcan nuevas reglas, pero los cambios deberán quedar documentados.
