# Capítulo 05 — Spring Boot, PostgreSQL, JPA y Hibernate (AutoCare 360)

## 1. Datos de Conexión y Base de Datos
- **Proyecto asignado:** AutoCare 360
- **Base de datos:** `autocare360`
- **Schema:** `public`
- **Tabla padre:** `cliente`
- **PK física:** `cliente_id` (BIGINT GENERATED BY DEFAULT AS IDENTITY)
- **Restricciones UNIQUE:** `documento_identidad` (UNIQUE global)

## 2. Decisiones Técnicas y de Persistencia
- **Estrategia `ddl-auto: validate`:** Se configuró estrictamente en modo `validate` en `application.yml` para garantizar que Hibernate no altere, cree ni destruya tablas automáticamente, sino que verifique que el modelo Java respeta el esquema físico previamente creado.
- **Separación entre Dominio y Persistencia:**
    - `Cliente.java` vive en `com.autocare360.cliente.domain.model` sin anotaciones `@Entity`, `@Table` ni `@Column`.
    - `ClienteJpaEntity.java` vive en `com.autocare360.cliente.infrastructure.adapter.out.persistence.entity` mapeando la tabla física real.
- **Mapper de Persistencia:** `ClientePersistenceMapper` realiza la traducción bidireccional entre la entidad JPA y el modelo de dominio.
- **Repositorio Spring Data:** `SpringDataClienteRepository` extiende de `JpaRepository<ClienteJpaEntity, Long>` y define `findByDocumentoIdentidad`.
