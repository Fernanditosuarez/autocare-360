# Guía 01 — Estructuración del Frontend con Vite, React y TypeScript (AutoCare 360)

## 1. Inicialización y Limpieza
- Proyecto generado con Vite bajo la plantilla `react-ts`.
- Limpieza de estilos y componentes demo de Vite (`react.svg`, `App.css`).
- Configuración de estilos base en `src/index.css`.

## 2. Arquitectura Feature-Based
- Estructuración orientada a dominios de negocio:
    - `src/features/clientes/` (tipos, componentes, páginas).
    - `src/features/vehiculos/` (tipos, componentes, páginas).
- Componentes iniciales de tarjeta: `ClienteCard.tsx` y `VehiculoCard.tsx`.
